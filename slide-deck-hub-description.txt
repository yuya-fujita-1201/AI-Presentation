slide-deck ― JSONからスライドをHTML/PowerPointに自動ビルドするClaude Codeプラグイン

「勉強会向けに○○を10枚で」「□□の提案書を作って」と頼むだけで、AIが構成を設計し、設計図となる1つのJSON（deck.json）を生成して、16:9のHTMLとPowerPoint(.pptx)を同時にビルドします。内容・レイアウト・配色をすべてdeck.jsonのパラメーターで管理するため、位置・サイズ・フォント・色の微修正や作り直しを正確かつ再現可能に行えます。既存のPowerPoint資料を見た目そのままにHTML化することもできます。

【主な特長】
・全29種類のスライドタイプに対応。要旨・選ばれる理由・全体像（屋根と柱）・体制図・KPIツリー・循環・行見出し×列の整理表・言い切りなど、提案書の定型ページを人が作った提案書と同じ型で描けます。結論の帯や出典の行もほぼ全タイプに付けられます。
・構成図・データフロー・状態遷移・シーケンス図・業務フロー(swimlane)は、ノードとエッジをJSONで書くだけで線を自動配線し、凡例も自動生成。矢羽根スケジュール（schedule）は期間を日付で書くだけで時間軸に合わせて自動配置します。
・PPTXでは四角・矢羽根・線・アイコンがすべてネイティブ図形になり、PowerPoint上で1つずつ編集できます。アイコンは公開ライセンス（MIT）の定番74点を同梱し、「コスト削減」「セキュリティ」のような言葉で選べます。
・新規作成の最初に、テーマ・聞き手・目的・構成の型・枚数・仕上げの度合いを1画面で選ぶ設定フォームを表示。選んだあとは確認なしで完成まで進めます。
・配色とフォントは「テーマトークン」で一括管理。同梱テーマは default と、アクセンチュアの3つのテンプレートに寄せた配色（Accenture / ACN Slide Master / ACN Technology Graphik）の4種。テーマの追加も容易です。
・はみ出し・重なり・文字あふれ・図解の配線衝突に加え、文言（曖昧語・構成の説明・日付の整合など）や見た目の偏りを機械チェック。「仕上げ」を選ぶと評価エージェントが採点し、低いページだけを直して再採点します。配布用PDF書き出しにも対応。

【導入・使い方・前提】Claudeアプリの Code タブにzipをアップロードするか、Claude Code CLI で読み込めばすぐ使えます。create-deck / add-theme / review-deck / export-pdf / setup の5スキルで、作成から検証・配布まで完結。Python 3.14以上とpython-pptxが必要です（プレビュー画像はPlaywright、字幅の実測と見た目のチェックはPillowがあると使えます）。

手作業でのスライド清書を、パラメーター編集と再ビルドに置き換えます。
