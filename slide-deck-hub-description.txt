slide-deck ― JSONからスライドをHTML/PowerPointに自動ビルドするClaude Codeプラグイン

「勉強会向けに○○を10枚で」と頼むだけで、AIが構成を設計し、設計図となる1つのJSON（deck.json）を生成して、16:9のHTMLとPowerPoint(.pptx)を同時にビルドします。内容・レイアウト・配色をすべてdeck.jsonのパラメーターで管理するため、位置・サイズ・フォント・色の微修正や作り直しを正確かつ再現可能に行えます。既存資料のHTML化・置き換えにも活用できます。

【主な特長】
・全19種類のスライドタイプに対応。構成図・データフロー・状態遷移・シーケンス図・業務フロー(swimlane)は、ノードとエッジをJSONで書くだけで線を自動配線し、凡例も自動生成。複雑な業務プロセスの可視化に強みがあります。
・配色とフォントは「テーマトークン」で一括管理。テーマの切替・追加が容易で、ブランドカラーにも対応。
・HTMLとPPTXの座標がほぼ完全一致。編集はブラウザで即プレビューできます。
・レイアウトのはみ出し・重なり・文字あふれ、図解の配線衝突を機械チェックする検証ツールを同梱し、品質を自動で担保。配布用PDF書き出しにも対応。

【導入・使い方・前提】Claudeアプリの Code タブにzipをアップロードするか、Claude Code CLI で読み込めばすぐ使えます。create-deck / add-theme / review-deck / export-pdf / setup の5スキルで、作成から検証・配布まで完結。Python 3.14以上とpython-pptxが必要です。

手作業でのスライド清書を、パラメーター編集と再ビルドに置き換えます。
