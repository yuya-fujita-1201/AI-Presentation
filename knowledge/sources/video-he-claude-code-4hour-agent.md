# 要点

## AIエージェントとは何か

- 動画は、これまでのChatGPTのようなチャット型AIは指示に対して回答が返って完結する形式が中心だったのに対し、現在は指示せずとも自分で動くAIへ進化していると位置づけ、この自分で動くものを「AIエージェント」と呼んでいると説明している（[04:00]、主張テーブルc1）
- MC野嶋さんは、複数のAIサービスをチャット形式で使ってきたが複雑な作業まではできていなかったと自己申告した上で、AIエージェントを本当に自分で構築できるのか楽しみにしていたと述べている

## 環境構築とクロードコード起動の体験

- Visual Studio Codeなど必要なソフトをインストールし初期設定を行った上で、20分程度でクロードコードをパソコン上で起動できたとしている
- 起動後、Googleカレンダーとの連携（MCPと呼ばれる仕組みを通じた連携だとしている）によって、その日のスケジュールをクロードコードが読み上げる様子を実演している

## クロードコードが注目される理由

- 動画は、クロードコードが一気に注目を集めた最大の理由として、パソコンの中に住み込んだ上でファイルを探し出せる点を挙げている（[08:00]、主張テーブルc2）
- ホワイトカラーの仕事はWord・PDF・Excel・CSV・パワーポイント・画像・動画・テキスト設定ファイルなど、結局のところほとんどがファイルの編集であり、ファイル操作能力の高いAIこそが最強のAIになり得ると説明している（[08:00]、主張テーブルc3）
- クロードコードはターミナルを通じてパソコンにコマンドで指示を出しており、人間が日本語で「フォルダーを作って」と依頼すると、裏側でmkdirコマンドが実行される仕組みだと解説している

## フォルダ整理の実演で動作原理を体感

- ターミナル操作の基礎（cd・ls・mkdir）を学んだ後、実際にバラバラだったファイル名・並び順を、特定の月のフォーマットを参考に整形させる実演を行っている
- クロードコードが重複候補をチェックサムで確認しようとする提案を出す場面があり、この結果MC野嶋さんが潜在的に別扱いしてほしいと思っていたファイルだけが正しく残ったと紹介されている

## 野嶋さん専用AIエージェントの構築

- MC野嶋さんが、企画立案のための情報収集からテーマ選定、専門家探し・アポ取り、台本作成までを一人で担っており、土日もフル稼働で情報収集をしている実情をホワイトボードに整理している
- この中でも特に時間がかかっている「情報を探す」工程に絞って、ニュースを収集し短くまとめてくれるAIエージェントを作ることに決めたとしている
- 「スキル」とは、プログラムが人間からパソコンへの指示書であるのに対し、AIに対して人間が作る業務マニュアルに相当するものであり、繰り返し作業を同じクオリティで実行できるようにするものだと説明している（[22:00]、主張テーブルc4）
- クロードコードが最初に提示したスキル作成の実行計画をそのまま採用するのではなく、「AIに任せすぎない」ことが重要だと指摘し、人間が担うべき部分とクロードに任せる部分を人間の知識で切り分けることがコツだとしている

## 完成したエージェントのデモと他AIサービスとの違い

- 完成した「ピボット企画」スキルを実行すると直近1週間のニュースからネタ候補を提示し、これを使えば通常週21時間かかっていた作業が10分程度で終わる可能性があるとMC野嶋さんが驚く場面が紹介されている
- 出力結果を見やすく表示するビューアーの作成もその場で依頼し、Webページとして仕上げている
- ChatGPTやGeminiのようなクラウド上のチャット型AIとの違いについて、それらはパソコンのファイルの中身を直接読みに行けないため悩みや参考資料のアップロードが都度必要になる上、ローカルデータを踏まえたビューアー作成のような操作もできないと指摘し、パソコンに住み込んで定期実行の設定までできる点にクロードコードの柔軟性があると説明している
