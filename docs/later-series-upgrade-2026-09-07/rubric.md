# 後半シリーズ改訂の評価基準

比較基準: decks/01-prompt-engineering と 02〜05。読者はAI初心者、第2章から実物に踏み込む。

1. 定義と理解順: 第1章の最初にテーマの一文定義、必要性、何をするか。
2. 深掘りと章のつながり: 第2章に仕組み・使い方・業務のメリットと条件、第3章に事例・原因の切り分け・応用、第4章以降にTips。
3. 実用性: 一貫した具体例、判断できる比較、試せるテンプレート、練習と解答。
4. 文章: 具体的な語、無意味な反復や標語・水増しなし、用語の一貫性。
5. 図の説明力とシリーズ整合: 本文と図の対応、重要部分の強調、01〜05と同等の説明の刻み。
6. 事実と出典: 架空例明示、主張の条件と一次資料対応、製品固有挙動と一般概念を区別。

採点者は実物と全ページ画像を読み findings のみ提出。重大度 大20・中5・小1（項目ごと100から減算、下限0）。2名なら低い方、3名なら中央値。全項目80以上に加え、テーマ定義欠如・指定章欠落・未解決の重大な誤情報は点数にかかわらず不合格。機械検証は別判定。中核3概念の一文定義と到達ページを本文だけで回答する。
