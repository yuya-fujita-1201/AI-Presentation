app-plugin-menu.png ... Claude アプリの Code タブで「カスタマイズ → プラグイン → 追加」を開いた画面のスクリーンショット（導入 A の 1 枚目）。作成者名とプロジェクト名が写っていたため、画像上で汎用の語（your-name / project）に置き換えてある。
  画像を撮り直すときは、個人名・プロジェクト名・メールアドレスが写らないようにするか、同様に置き換えること。
app-plugin-upload.png ... 「プラグインをアップロード」の画面のスクリーンショット（導入 A の 2 枚目）。同じく、プロジェクト名を project に置き換えてある。
terminal-setup.png ... 「python setup_deps.py --check」の実際の出力をターミナル風 HTML に流し込み Playwright でスクリーンショットしたもの（2 倍解像度）。表示パスは利用者の環境を想定して Windows 風（C:\Users\you\...）に置換済み。
folder-project.png ... 利用者のデッキフォルダ（decks/kickoff）の構成（deck.json / assets / build/ の HTML・PPTX・プレビュー PNG）を tree 風テキストとしてターミナル風 HTML に書き起こし、同様にスクリーンショットしたもの（2 倍解像度）。
cover-panel.jpg ... 表紙（variant: split）の左パネル用の抽象画像。Pillow で自作（中立の濃いスレートに細い線でつないだ点）。外部の写真・ロゴは使っていない。
bg-dark.jpg ... 言い切り・締めの背景用の抽象画像（同上）。examples/template-sample/assets/ の同名ファイルと同じもの。
