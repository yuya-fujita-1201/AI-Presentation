2章 / 基本
基本：こう頼む
リポジトリのフォルダで、作りたい内容を日本語で伝えるだけです。
slide-deck プラグイン ユーザーガイド
10 / 23
  • 例：「AI導入の社内勉強会向けに10枚くらいのスライドを作って。テーマは accenture-purple で」
  • Claude が deck.json を作成 → ビルド → プレビューまで行う
  • 構成から相談してもよい：「まず目次だけ提案して」
  • 手元の箇条書き・メモ・既存資料を渡すと、それを元に組み立てる
  • プラグイン導入時は /slide-deck:create-deck でも起動できる
2章 / テーマ指定
テーマ（配色・フォント）の指定
見た目のトーンは『テーマ』で決まります。指示で切り替えられます。
slide-deck プラグイン ユーザーガイド
11 / 23
  • 「テーマは accenture-purple で」／「default（青系）で」＝同梱テーマを指定
  • 指定しなければ default（青系）になる
  • ブランド色を直接伝える：「primary を #460073、accent を #A100FF で」
  • 「このPPTXと同じ配色で」＝サンプルからテーマ生成（本章後半）
  • あとから「テーマを◯◯に変えて」の一言で全体を切替できる

2章 / Tips
良いスライドのコツ
頼み方を少し工夫すると、仕上がりが安定します。
slide-deck プラグイン ユーザーガイド
13 / 23
  • 1スライド＝1メッセージ。詰め込みすぎない
  • 箇条書きは5〜6行まで。多いなら分割か 2カラムに
  • 図は image_text で説明と一体に（図だけ・文だけに分けない）
  • まず章立て・目次を固めてから中身を作る
  • プレビューを見て「ここをこう」と微修正を重ねる
2章 / Dos & Don'ts
やること・避けること
この仕組みを気持ちよく使うための指針です。
slide-deck プラグイン ユーザーガイド
14 / 23
Do
  • 内容を箇条書きで渡す
  • テーマを指定する
  • プレビューで確認→微修正
  • 色はテーマに任せる
Don't
  • build/ や PPTX を手で直す
  • 1枚に詰め込みすぎる
  • 色を hex で直書き
  • 毎回「全部作り直して」
2章 / 微修正
微修正の頼み方
作り直さず、その1点だけを直せます。該当スライドの style に差分が入ります。
slide-deck プラグイン ユーザーガイド
15 / 23
  • 「5枚目のタイトルをもう少し大きく」
  • 「この表の1列目を広くして」
  • 「3枚目の箇条書きの2つ目を強調して」
  • 「全体の余白をもう少し詰めて」
  • → 位置・サイズ・色・フォントの微調整はすべて差分で完結
2章 / テーマ追加
テーマを追加したいとき
独自の配色テーマを増やせます。default を継承するので差分だけでOK。
slide-deck プラグイン ユーザーガイド
16 / 23
  • 「brand-navy というテーマを作って。primary は #1F3A5F」→ 雛形を生成
  • 変えたい色だけ指定すればよい（残りは default から継承）
  • 「このPPTX/画像/PDFからテーマを作って」＝サンプルから抽出（次ページ）
  • 独自テーマは SLIDE_DECK_THEMES に置けばプラグイン更新で消えない
  • プラグイン導入時は /slide-deck:add-theme でも起動できる

3章 / 思想
なぜ JSON で管理するのか
内容とデザインをデータとして分離することに、いくつも利点があります。
slide-deck プラグイン ユーザーガイド
22 / 23
  • 分離：微修正は数値を変えるだけ。作り直し不要
  • 再現性：テキストなので Git で差分管理・レビュー・巻き戻しができる
  • AI 親和性：該当箇所だけを安全に差分編集できる
  • 一元生成：1ソースから HTML と PPTX を作るので見た目が一致し二重管理が不要
  • テーマ化：色をトークンで持つので、切替で全体を一括変更できる
