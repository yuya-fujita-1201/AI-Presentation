OVERVIEW
これは何か
スライドの「内容」と「デザイン」を分離し、すべてを deck.json のパラメーターで管理する仕組みです。
slide-deck プラグイン ユーザーガイド
3 / 15
  • 1つの deck.json から HTML と PowerPoint(16:9) を生成する
  • 内容もデザインも JSON のパラメーター。仮想キャンバス 1280×720px に px 指定
  • HTML と PPTX は同じ値を読むので見た目が一致する
  • AI（Claude Code）でもヒトでも、同じルールで作成・微修正できる
    • 作成・編集: /slide-deck:create-deck
    • テーマ追加: /slide-deck:add-theme
  • 色はテーマトークンで指定 → テーマを変えるだけで全体の配色が変わる

THEMES
テーマの切替・追加
テーマは色トークン14種＋フォント3種。default をベースにマージされます。
slide-deck プラグイン ユーザーガイド
11 / 15
  • 切替は meta.theme を変えるだけ（同梱: default / accenture-purple）
  • 追加は 2通り
    • /slide-deck:add-theme または new_theme.py で雛形を作る
    • default 継承なので上書きしたいトークンだけ書けばよい
  • 探索順は SLIDE_DECK_THEMES(環境変数) → <deck_dir>/themes → 同梱
  • ユーザー独自テーマは SLIDE_DECK_THEMES に置けば更新で消えない
  • トークンの意味は references/themes.md を参照

RULES
注意事項（厳守）
配布・互換性のために守るべき点です。
slide-deck プラグイン ユーザーガイド
13 / 15
  • PPTX にスピーカーノートを入れない（Keynote 互換性を壊す）
  • notes フィールドは HTML の N キーでのみ表示される（ビルダーが自動処理）
  • 色は必ずテーマトークンで指定。hex 直書きはテーマ切替を無効化する
  • 生成物（build/）は直接編集しない。必ず deck.json を直して再ビルド
  • 図解は原則 image_text（図と説明を1枚に統合する）
TROUBLESHOOTING
トラブルシュート
よくある症状と対処です。
slide-deck プラグイン ユーザーガイド
14 / 15
症状対処
PPTX が作れない / python-pptx が無い/slide-deck:setup（pip install python-pptx）
プレビュー PNG が出ない/slide-deck:setup --playwright
PPTX を上書きできない（Permission denied）PowerPoint 等でそのファイルを閉じる
フォントが違って見えるテーマの fonts を閲覧環境にあるフォントに変更
追加したテーマが更新で消えるSLIDE_DECK_THEMES にユーザー用フォルダを設定
使い始めましょう
  • 依存を入れて（/slide-deck:setup）、作りたい内容を頼むだけ
  • 微修正は deck.json の style に差分を書いて再ビルド
  • 配色はテーマで一括管理。既存スライドからテーマも起こせる
