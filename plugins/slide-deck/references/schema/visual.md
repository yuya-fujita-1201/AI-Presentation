# 大きな数字とグラフ（`kpi` / `chart`）

共通事項は索引 [`../deck-schema.md`](../deck-schema.md)。数字・推移・比較を「主役」にするタイプ。表（`table`）より、結論の数字が一目で伝わる。

レイアウトは `tools/dataviz_engine.py` が計算し、HTML と PPTX の両方で**ネイティブ図形**（PowerPoint で棒・線・ラベルを 1 つずつ選べる。数値をあとから直せる）になる。色はテーマから作る（強調色 `accent` は「変化後の値」「`highlight` に挙げた項目」だけ。それ以外は `primary` / `muted` の落ち着いた色）。結論の帯 `conclusion` と出典 `source` が使える。本文は `body` 領域（`lead` が無ければ `y_no_lead` まで上に詰める）。領域: `eyebrow` / `title` / `rule` / `lead` / `body` / `footer_l` / `footer_r`。文字の大きさは矩形の大きさに合わせて自動で縮む。

## `kpi` — 大きな数字

```json
{ "type": "kpi", "title": "提案書の作成時間は3分の1になった", "lead": "（任意）",
  "items": [
    { "value": "2.1", "unit": "時間", "label": "提案書1件の作成時間", "from": "6.5", "delta": "−68%", "good": "down",
      "note": "パイロット3チーム12名・2か月" },
    { "value": "9", "unit": "%", "label": "上長レビューの差し戻し率", "from": "22" },
    { "value": "9", "of": "12", "unit": "部署", "label": "ヒアリング完了" } ],
  "conclusion": "（任意）", "source": "（任意）" }
```

- `items` は **1〜4 件が目安**（5〜6 件は 3 列 2 段、7 件以上は 4 列。5 件以上は警告）。**1 件なら主役 1 つを全面に**（数字は 100px 級）、2 件以上は横に並べたタイルになり、数字の大きさ・行の位置は全件でそろう。2 件以上で `from` があるとき、`from` を「6.5 時間 →」の小さい 1 行にして数字の上に分けたほうが数字を 1.25 倍以上大きくできるなら自動でそうする（数字は 50〜60px 級）。
- 項目のキー:

| キー | 意味 |
|---|---|
| `value` | 必須。数値でも文字列でも可（数値は桁区切りになる） |
| `unit` | 数字より小さく、ベースラインをそろえて右に付く |
| `label` | 上の説明 |
| `from` | 変化前の値。`6.5 時間 → 2.1 時間` を 1 行で出し、変化前は灰・変化後だけ強調色。`unit` は `from` にも付く（単位が違うときは `from_unit`。下の注） |
| `from_unit` | 変化前に付ける単位。`"from": "3", "from_unit": "か月", "unit": "週間"` → 「3 か月 → 6 週間」。`""` で単位なし |
| `delta` | 変化量の文字列（`−68%`）。丸いチップで表示 |
| `good` | `"up"`（増えると良い）/ `"down"`（減ると良い）。動きが良い側なら緑、悪い側なら赤、`good` が無ければ灰。チップの文字は背景との対比が 4.5:1 になるまで自動で暗くする。動きは `from` と `value` の大小、無ければ `delta` の先頭の `+` / `−` で判定 |
| `note` | 下の注記（灰） |
| `of` | 全体の数。`9 / 12 部署` と進捗バーになる。`from` とは併用しない（併用すると、`from` を優先して `of` を無視し、警告） |
| `emphasis` | `false` で強調色を使わない |

- **単位が違う変化（「3か月 → 6週間」）**: `from_unit` で変化前の単位を分ける（`"from": "3", "from_unit": "か月", "value": "6", "unit": "週間"`）。`from` に「3か月」のように単位込みの文字列を書いたときも、`unit` は重ねて付かない（「3か月 → 6 週間」と出る）。数字だけの `from` には従来どおり `unit` が付く。換算が材料にあるなら単位をそろえてもよい（「13週間 → 6週間」。換算した数は根拠を `note` に）。そろえられず、矢印で見せたくないときは **2 項目に分ける**（タイトルか `lead` で「3か月から6週間へ」と言い切る）。
- 2〜4 件のタイルは本文領域の高さの 94% 以上まで伸びる（`body.tile_min_ratio`）。数字の大きさの上限は、1 件のとき `hero_max_size` 120px、2 件以上のとき `tile_max_size` 100px。
- 強調色は変化後の値だけ。`from` を持つ項目が 3 件以上あるときは、全部が強調色にならないよう既定では強調しない（`emphasis: true` で個別に指定）。
- 入りきらないとき（小さい矩形・件数が多い）は、注記 → 変化 → ラベルの順に自動で省く。
- 数字を長い文字列にしない。`value` が数字で 10 桁を超えるときは万・億に換算、文字混じりで 8 文字を超えるときは単位を `unit` へ（警告）。数字が決まるまでの仮置きは `"value": "【要確認】"`（6 文字。確かめる点まで書くと `【要確認: 金額】` が 8 文字を超えて警告になるので、確かめる点は `note` か骨子に書く）。強調表示は大きな数字のまま黄色い下地で出る。
- `style.body` トークン: `gap` / `pad_x` / `pad_y` / `radius` / `hero_max_size`（既定 120）/ `tile_max_size`（既定 100）/ `tile_min_ratio`（既定 0.94）/ `min_size` / `value_size`（数字の大きさを固定）/ `tile_fill` / `label_color` / `value_color` / `to_color` / `from_color` / `note_color` / `bar_fill` / `bar_track` / `good_color` / `bad_color` / `chip_tint`。
- 余白が多いのが普通のタイプ（`check_visual.py` は下の空白を警告しない）。数字を大きく見せるための余白なので、無理に埋めない。

## `chart` — データグラフ

```json
{ "type": "chart", "title": "パイロット開始後、作成時間は6.5時間から2.1時間へ下がった",
  "chart": "bar", "unit": "時間",
  "categories": ["Q1", "Q2", "Q3", "Q4（見込み）"],
  "series": [{ "name": "作成時間", "values": [6.8, 6.5, 2.4, 2.1] }],
  "highlight": ["Q3", "Q4（見込み）"], "forecast_from": "Q4（見込み）",
  "annotations": [{ "at": "Q3", "text": "パイロット開始" }],
  "y": { "min": 0, "max": 8, "label": "時間／件" }, "values": true,
  "note": "Q3から下がり、見込みも同水準", "conclusion": "（任意）", "source": "（任意）" }
```

- `chart`（種類。省略すると `bar`）:

| 種類 | 用途 |
|---|---|
| `bar` | 縦棒。複数系列は並べる（別名 `column` / `vbar`） |
| `hbar` | 横棒。ランキング・長いラベル向き（別名 `barh`） |
| `stacked` | 積み上げ。合計を上に表示（別名 `stack` / `stacked_bar`） |
| `line` | 折れ線。複数系列（別名 `lines`） |
| `waterfall` | 増減の内訳 |
| `donut` | 構成比。系列は 1 つ。中央に合計。値が穴に収まるよう文字を縮め、収まらなければ単位を外し、百分率で 100% のときは出さない。凡例は名前と構成比を近づけた 1 つの塊で、矩形が狭いときは輪の下に置く。置けなければ警告して凡例を省く（別名 `pie` / `ring`） |

- `categories`（項目名。重複させない）と `series`（`[{name, values, color?}]`）。`values` の個数は `categories` と同じにする（欠測は `null`）。系列が 1 つなら凡例を出さない。系列は 5 本程度まで。色の既定は `primary` → `accent` → `muted`（それ以降は混色）。`color` はテーマの色名か `#RRGGBB`（6 桁）。それ以外（`red` や `#abc`）はビルドエラー。
- `highlight`: 強調する項目名（または系列名）の配列。**指定した項目だけ `accent`、ほかは淡い灰青**（1 系列のとき）。無指定なら全部 `primary`。項目名にも系列名にも一致しない名前だけを書いたときは強調なし（警告は出る）。`bar` / `hbar` / `donut` で同じ動き（系列名での強調は `bar` / `hbar` / `line`）。
- `forecast_from`: この項目以降を見込みとして淡色＋破線で描く（折れ線は破線）。
- `annotations`: `[{at, text, series?}]`。対象の上に短い吹き出し（20 字以内が目安・3 個以内）。値ラベル・他の注釈・**隣の棒**に重ならないよう、横にずらす → 箱を細くして折り返す → 上の段へ上げる、の順で置く（置けなければ警告）。
- `y`: `{min, max, step, label, grid}`。目盛は切りのよい値を自動で決める。`label` は左上の単位の説明（無ければ `unit` から「単位：…」）。`grid` は既定で、値ラベルを出すときは無し、出さないときは有り。**棒グラフは 0 起点が原則**（`y.min` が 0 でないと警告）。`y.min` がデータの最小値より大きいときも警告。
- `values`: 値ラベル。`true`（既定）/ `false` / `"ends"`（折れ線で最初と最後の点だけ。系列が複数または点が 12 個超なら自動でこれ）。桁区切りと単位つき。隣と重なるときは単位を外す → 文字を小さくする、の順で収める。負の値は棒が基準線の下に伸び、ラベルは棒の外側。小さい値（0.004 など）は 0 に丸めず桁を増やして表示する。`hbar` で項目 × 系列が多く値ラベルが入らないときは、ラベルを省いて目盛を出し、警告する。`stacked` に負の値があるとき、上の数字は差し引き後の合計で「差引 90」と表示する。
- `note`: 右側（矩形幅 640px 以上）に置く読み取りの一言。幅が狭い矩形では下の一行になる。
- `waterfall` 専用: `series[0].values` に開始・増減・合計の順で書く。`totals`（合計として扱う項目名の配列。既定は先頭と末尾）。合計の値が `null` なら積み上げから自動で出す。`good`（`"up"` / `"down"`）で増減を緑・赤に塗り分ける（無指定は増加 = `accent`、減少 = 淡い灰青）。
- `style.body` トークン: `tick_size` / `cat_size` / `value_size` / `legend_size` / `note_size` / `anno_size` / `min_size`（下限 11px）/ `base_color` / `highlight_color` / `series_colors`（配列）/ `fade_tint` / `forecast_tint` / `grid_color` / `axis_color` / `bar_max_w`（棒の太さの上限 px、既定 96）/ `bar_gap` / `line_w` / `marker` / `anno_fill` / `anno_color` / `note_fill` / `note_bar` / `good_color` / `bad_color` / `donut_hole`。

### 使い分けの目安

- 変化前→後の 1〜4 個の数字は `kpi`。時系列の推移・項目間の比較・内訳は `chart`。正確な数値を読み取らせる一覧、列が多いものは `table`。
- タイトルは「何が・どれだけ・どうなった」の結論文にし、グラフはその根拠にする（「売上の推移」ではなく「売上は2年で1.8倍になった」。[../content-guide.md](../content-guide.md)）。強調（`highlight` / `forecast_from` / `annotations`）は結論に関わる 1〜3 点に絞る。
- 数字は材料にあるものだけを使う。無いものは `【要確認: …】`（索引の「根拠が無い箇所は `【要確認】` と書く」）。`values` に `【要確認】` は書けないので、`null`（欠測）にして `note` か `notes` に書く。

## 検証（ビルドエラー = ビルドを止める / 警告 = 続行）

| 内容 | 重さ | 直し方 |
|---|---|---|
| `chart` の種類の打ち間違い | エラー（候補つき） | 種類を直す |
| `categories` / `series` が無い・`values` の個数が合わない・数値でない値 | エラー | 個数をそろえる・数値にする（欠測は `null`） |
| `forecast_from` / `annotations[].at` が `categories` に無い | エラー（候補つき） | 項目名を直す |
| `y.min` ≥ `y.max`・`donut` に負の値 | エラー | 値を直す |
| `series[].color` がテーマの色名でも `#RRGGBB` でもない | エラー（候補つき） | 色名か 6 桁の hex にする |
| `kpi` の `items` / `value` が無い・`value` が文字列でも数値でもない・`good` が up / down でない | エラー | 書き足す・直す |
| 項目が多い（bar 13 以上・hbar 16 以上）・系列 6 本以上・`kpi` 5 件以上 | 警告 | hbar にする・絞る・cards / table にする |
| 未知キー（候補つき。スライド直下・`items[]`・`series[]`・`annotations[]`・`y`・`style.body`）・`highlight` が項目にない・`y.max` がデータより小さい・`y.min` がデータの最小値より大きい・棒グラフの `y.min` が 0 でない | 警告 | キー名を直す・軸を直す |
| `categories` に同名の項目・`values` がすべて `null`・`annotations[].series` が系列名にない | 警告 | 項目名を区別する（例: Q1（2025））・値を入れる・系列名を直す |
| `kpi` の `items` に値だけの文字列・`of` と `from` の併用（`from` を優先して `of` は無視）・`value` が長い | 警告 | 形を直す（進捗にしたいなら `from` を消す。変化にしたいなら `of` を消す） |
| 値ラベル・注釈・カテゴリ名が重なる、棒が細すぎる（4px 未満）、`hbar` の値ラベルが入らず省かれた、`donut` の凡例を置けない、描く領域が小さすぎる | 警告 | 項目・系列を減らす・hbar / 縦棒 / stacked にする・注釈を短くする |
| `waterfall` の合計が積み上げと合わない | 警告（【要確認】） | 値を確かめる |
